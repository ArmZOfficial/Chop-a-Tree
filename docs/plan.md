## 1. เนื้อเรื่อง — "The Withering"

1. บน **เกาะลอยฟ้า** สุดปลายทวีปมี **ต้นไม้มหาเทพ Lumora** ต้นไม้ที่ให้ชีวิตกับทั้งป่า รากของมันห้อยลงมาหล่อเลี้ยงทั้งทวีป
2. **"ราเน่า" (The Rot)** — พลังเน่าเปื่อยสีม่วง — ไหลลงตามราก Lumora กัดกินป่าจากปลายทวีปเข้ามา ต้นไม้กลายเป็นไม้แข็งผิดธรรมชาติ สัตว์ทิ้งไข่หนีเข้าป่าลึก
3. ผู้เล่นคือ **คนตัดไม้ฝึกหัด** ที่มาถึง **หมู่บ้าน Rootfall** ต้นทวีป ได้รับขวานจาก NPC **ปู่ Bram** หัวหน้าหมู่บ้าน
4. ภารกิจ: ตัดต้นไม้ที่ติดราเน่า ปลูกต้นไม้ใหม่ให้ป่ากลับมา เลี้ยงสัตว์ที่ฟักจากไข่ที่ถูกทิ้ง แล้วเดินทางข้ามทวีปไปชำระ Lumora
5. แต่ละโซนมี **ศาลเจ้าป่า (Shrine)** ที่ดับอยู่ และ **ต้นไม้ผู้พิทักษ์ (Guardian Tree)** ที่ถูกราเน่าครอบ = บอสของโซน
6. ล้มบอส → จุดศาลเจ้า → คัตซีนสั้น → ทางไปโซนถัดไปเปิด → บทถัดไปของเรื่อง
7. ขึ้นเกาะลอยฟ้าชำระ Lumora ได้ = จบบทหลัก → **Rebirth = "วัฏจักรใหม่"** ราเน่ากลับมาแรงกว่าเดิม (เรื่องต่อได้ไม่รู้จบ)

### 1.1 โทนเรื่อง — ผสม (ผจญภัย + ตลกน่ารัก)

1. **เส้นเรื่องหลักจริงจัง**: ราเน่ากำลังกินป่า, ความลับว่าใครปล่อยราเน่า, บอสแต่ละตัวมีเหตุผลที่ถูกครอบ, ฉากชำระศาลเจ้าซึ้งๆ พร้อมเพลง
2. **ตัวละครรอบข้างตลก**:
   - ปู่ Bram เล่ามุกพ่อๆ ทุกครั้งที่คุย และชอบโม้ว่าเคยตัดต้นไม้ด้วยช้อน
   - พ่อค้าเร่เป็นกระรอกพูดเยอะ ต่อราคาเก่ง
   - นักวิจัยราเน่าซุ่มซ่าม ทดลองแล้วระเบิดบ่อย
   - สัตว์เลี้ยงมีท่าทางน่ารัก/โง่ๆ ตอนว่าง
3. **ช่วงพีคแบบอนิเมะ**: บอสมีฉากเปิดตัว + ชื่อขึ้นจอ, ตอนล้มบอสมี slow motion + เส้นสปีด
4. บทพูดสั้น อ่านเร็ว กดข้ามได้เสมอ

| บท | โซน | เหตุการณ์หลัก |
|---|---|---|
| 1 | ทุ่งหญ้าแสงแดด | เรียนตัดไม้, ปลูกต้นแรก, ฟักไข่ใบแรก |
| 2 | ป่าเมเปิลฤดูใบไม้ร่วง | พ่อค้าเร่มาถึงหมู่บ้าน, เปิดระบบหีบระดับสูง |
| 3 | บึงเห็ดเรืองแสง | เจอ NPC นักวิจัยราเน่า, เปิดระบบ Mutation |
| 4 | ที่ราบซากุระ | สำนักดาบลับ เปิดระบบท่า/ธาตุอาวุธ |
| 5 | ป่าไผ่สายฟ้า | ศัตรูขโมยไข่ (NPC) โผล่ |
| 6 | ทุ่งน้ำแข็ง | พายุหิมะ, ต้องมีเสื้อกันหนาว (อัปเกรด) |
| 7 | ทุ่งคริสตัล | ความลับว่าใครปล่อยราเน่า |
| 8 | เกาะลอยฟ้า + Lumora | บอสสุดท้าย, จบบท → Rebirth |

## 2. Core Loop — 3 วงที่ป้อนกันเอง

```
        ┌─────────── ฟันต้นไม้ (Run) ───────────┐
        │  ได้ Wood / Coins / EXP / หีบ / ไข่ / เมล็ด │
        ▼                                         │
   เปิดหีบ → อาวุธแรงขึ้น ───────────────────────►│
        │                                         │
   ปลูกสวน (เมล็ดจากป่า) → รายได้ต่อเนื่อง + บัฟ ──►│
        │                                         │
   ฟักไข่ → สัตว์เลี้ยง → รายได้/วินาที + ช่วยฟัน ───┘
```

1. **วง A — ฟันต้นไม้ (Run)**: เดินออกจากหมู่บ้านเข้าป่า → ฟัน → เก็บหีบ/ไข่/เมล็ด → กด End Run → กลับหมู่บ้าน
2. **วง B — สวน (Grove)**: เอาเมล็ดที่ได้ไปปลูกในฐานตัวเอง → โตตามเวลาจริง → เก็บผล/ยางไม้/คริสตัล ขายเป็นเงิน
3. **วง C — ไข่และสัตว์ (Nest)**: เอาไข่มาฟักในฐาน → ได้สัตว์ → สัตว์สร้างเงินต่อวินาทีในคอก และติดตัวไปช่วยฟัน (บัฟ)
4. **ป้อนกัน**: เงินจากสวนและสัตว์ซื้ออัปเกรด/เมล็ด/ไข่ → ฟันได้แรงขึ้น → ไปโซนลึกขึ้น → ได้เมล็ดและไข่หายากขึ้น

## 3. แมพ — แมพเดียว ทวีปกว้างแนวนอน (ร่างที่ 9: เลิกภูเขาเกลียว)

### 3.1 ผังรวม (ArmZ เลือก: ทางคดเคี้ยวผ่านทวีปกว้าง, ราบมีเนินเตี้ยๆ, โซน ~500×500, เกาะลอยเหนือจุดปลายทาง)

```
 เหนือ (−Z)
 ┌───────────┬───────────┬───────────┬───────────┐
 │ 7 คริสตัล │ 6 น้ำแข็ง │ 5 ไผ่     │ 4 ซากุระ  │   แถวบน: เดินกลับทางตะวันตก
 │  ☁ เกาะ 8 │           │           │           │
 │  ลอยเหนือ │           │           │     ▲     │

 │           │           │           │     │     │
 │ หมู่บ้าน  │ 1 ทุ่งหญ้า│ 2 เมเปิล  │ 3 บึงเห็ด │   แถวล่าง: เดินไปทางตะวันออก
 │ Rootfall ─┼──────────►┼──────────►┼─────┘     │
 └───────────┴───────────┴───────────┴───────────┘
 ใต้ (+Z)                                      ตะวันออก (+X)
```

1. **หมู่บ้าน Rootfall** อยู่มุมตะวันตกเฉียงใต้ (จุดเกิด, ฐานผู้เล่น 7 ฐาน, ร้าน, NPC, กระดานผู้นำ, ประตูสู่ป่า, พอร์ทัล PvP)
2. ทางเดินหลัก **คดเป็นรูปตัว S**: แถวล่างไปตะวันออก (โซน 1→3) → ข้ามสะพานแม่น้ำที่โค้ง → แถวบนกลับตะวันตก (โซน 4→7) → **เกาะลอยฟ้า (โซน 8)** ลอยสูงเหนือโซน 7 เห็นได้จากทุกที่ในแมพ = เป้าหมายของเรื่อง
3. **ราบ มีเนินเตี้ยๆ**: แต่ละโซนสูงกว่าโซนก่อน ~8–12 studs ต่อกันด้วยทางลาด รู้สึกว่าเดินหน้าแต่ไม่ใช่ภูเขา
4. ขอบเขตระหว่างโซนเป็นธรรมชาติ: **กำแพงหนามราเน่า** สีม่วง, เนินหิน, แนวต้นไม้หนา, แม่น้ำ (คั่นแถวบน/ล่าง) — ผ่านได้เฉพาะ **ประตูราเน่า**
5. ระหว่างโซนมี **ประตูราเน่า** ปิดอยู่ เปิดเมื่อล้มบอสโซนก่อน + พลังถึงเกณฑ์
6. ทุกโซนมี **หินวาร์ป** กลับหมู่บ้าน และวาร์ปไปโซนที่ปลดล็อกแล้ว
7. ขึ้นเกาะลอยโซน 8: **รากลอยฟ้า** (บันไดรากเกลียวรอบเสาแสง) จากปลายโซน 7 + วาร์ปเมื่อปลดล็อก
8. เปิด **StreamingEnabled** เพราะแมพใหญ่
9. ขนาดปรับล่าสุด (ArmZ ขอให้ชิดกัน): โซนพื้นดิน ~500×480 studs, grid 500 → ขอบโซนในแถวเดียวกันติดกัน **ไม่มีช่องว่าง**; แม่น้ำคั่นสองแถวกว้าง 20 studs → ทวีปรวมประมาณ **2,100 × 1,100 studs** (+ ทะเลรอบทวีป). พื้น 4–64, เกาะลอย Y=364 (สูงกว่าโซน 7 300 studs). ทางลาดเข้าโซนเจาะพื้นรับไว้ ไม่เกิดขั้นต่างระดับ.

### 3.3 สิ่งที่มีในแต่ละโซน

1. ต้นไม้ 6 ระดับ (หัวข้อ 4.3) ต้นแข็งกว่าอยู่ลึกกว่า

3. **รังไข่ (Nest)** มีสัตว์ผู้พิทักษ์เฝ้า (หัวข้อ 4.7)

5. NPC เนื้อเรื่อง 1–2 ตัว

### 3.4 หมู่บ้าน Rootfall (Hub)

1. **ฐานผู้เล่น 7 ฐาน** แต่ละฐานมี: แปลงสวน, ตู้ฟักไข่, คอกสัตว์, ป้ายชื่อเจ้าของ, ปุ่มล็อกฐาน
2. **ร้าน**: ร้านเมล็ด (สต็อกใหม่ทุก 5 นาที), สายพานไข่ (ไข่วิ่งผ่าน กดซื้อ), ร้านอัปเกรด, โรงเลื่อย (ขาย Wood)
3. **แท่นเปิดหีบ** + เครื่องหลอมอาวุธ (Fuse)
4. **กระดานผู้นำ** และ **ป้ายเควส**
5. **ประตูสู่ป่า** = จุดเริ่ม Run
6. **พอร์ทัล Arena** ไปแมพ PvP

## 4. ระบบหลัก

### 4.1 Run (การออกไปฟัน) — UI ตามรูปตัวอย่าง

1. เดินผ่าน **ประตูสู่ป่า** = เริ่ม Run (ตัวคูณรอบเริ่มที่เลเวล 1)
2. ไม่มีจำกัดเวลา กด **End Run** เมื่อพร้อม → วาร์ปกลับหมู่บ้าน → หน้าสรุปผล → เปิดหีบ
3. **แผงขวาของจอ (เหมือนรูป)**:
   - ปุ่ม **Auto Attack (ON/OFF)** สีเขียว ไอคอนขวาน
   - ปุ่ม **Auto Cut (ON/OFF)** (ใหม่ หัวข้อ 4.2)
   - ปุ่ม **End Run** สีแดง
   - **รายการหีบที่เก็บได้** เรียงแนวตั้ง เลื่อนได้ แต่ละหีบแสดง **"LEVEL xx"** (เลเวลรอบตอนเก็บ ยิ่งสูงของยิ่งดี) และหีบซ้ำกันซ้อนเป็น **x2, x3**
4. หีบ/ไข่/เมล็ดที่เก็บระหว่าง Run **ยังไม่ปลอดภัย** จนกว่าจะกด End Run (ถ้าออกเกมกลางคัน ระบบ End Run ให้อัตโนมัติ ไม่หาย)
5. ระหว่าง Run: HUD บนบอก เลเวลรอบ + แถบ EXP + ตัวคูณปัจจุบัน + Wood/Coins ที่ได้ในรอบนี้

### 4.2 Auto Attack vs Auto Cut

| โหมด | ทำอะไร | ผลตอบแทน |
|---|---|---|
| Auto Attack | ฟันอัตโนมัติเมื่อยืนใกล้ต้นไม้ (ผู้เล่นเดินเอง) | 100% |
| **Auto Cut** | ตัวละคร **เดินหาและฟันต้นไม้ให้เอง** (Pathfinding) เลือกต้นที่ฟันได้ใกล้ที่สุด เลี่ยงรังไข่/บอส | **EXP, Wood, Coins −45%** (ได้ 55%) |

1. Auto Cut เดินอยู่ในโซนที่ผู้เล่นอยู่เท่านั้น ไม่ข้ามประตูโซน
1.1 **สิ่งที่โดนหัก −45%**: EXP, Wood, Coins, โอกาสดรอปเมล็ด
1.2 **หีบ**: เก็บได้เท่าเดิม แต่ LEVEL หีบต่ำลงเองประมาณ 3–4 เลเวล (เพราะ EXP น้อยลง เลเวลรอบจึงขึ้นช้ากว่า)
1.3 **ไข่**: Auto Cut ไม่หยิบไข่จากรัง (ต้องเล่นเอง) — เป็นรางวัลของคนเล่นจริง
1.4 **ผลจำลอง** (`balance_sim.py`): Auto Cut ได้ผลรวม **50–55% ของการเล่นเอง** ตรงกับ −45% จริง ไม่มีโทษแอบแฝง
2. เก็บหีบที่ขวางทางให้อัตโนมัติ
3. มีไอคอน "−45%" สีแดงข้างปุ่ม ให้รู้ตลอดว่าโดนหัก
4. หยุดเองเมื่อผู้เล่นกดเดิน/กระโดด
5. **AFK ได้**: เปิดทิ้งไว้แล้วไปทำอย่างอื่นได้ เกมกันโดนเตะออกเพราะ idle ให้
6. ระหว่าง AFK: หีบเก็บเข้ารายการอัตโนมัติ (เต็ม 50 ใบแล้วเก็บแค่ Wood/Coins/EXP ต่อ), ฐานได้ **โล่อัตโนมัติ** หลัง AFK 10 นาที (ไข่ไม่โดนขโมยตอนไม่อยู่)
7. ลดการหักได้ด้วย **ต้นไม้ทักษะ Rebirth เท่านั้น** (−45% → ต่ำสุด −25%) — **ไม่มีทางซื้อด้วยเงินจริง**

### 4.3 ต้นไม้ — 6 ระดับต่อโซน, ×100 ต่อโซน

| ระดับ | ชื่อ (ชั่วคราว) | HP โซน 1 | Power ขั้นต่ำ โซน 1 | EXP | Wood | Coins |
|---|---|---|---|---|---|---|
| 1 | ต้นกล้า | 1K | 0 (ฟันได้เสมอ) | 500 | 250 | 100 |
| 2 | ต้นเล็ก | 3K | 375 | 1.5K | 750 | 300 |
| 3 | ต้นกลาง | 7K | 875 | 3.5K | 1.75K | 700 |
| 4 | ต้นใหญ่ | 12K | 1.5K | 6K | 3K | 1.2K |
| 5 | ต้นเก่าแก่ | 20K | 2.5K | 10K | 5K | 2K |
| 6 | ต้นราเน่า | 30K | 3.75K | 15K | 7.5K | 3K |

1. โซน N = ค่าโซน 1 × 100^(N−1) → โซน 8 HP **100Qa – 3Qi** (บันไดต่อเนื่อง: ต้นระดับ 6 → ต้นระดับ 1 โซนถัดไป ห่าง ×3.3 เท่ากับก้าวภายในโซน)
2. Power ขั้นต่ำ = HP ÷ 8 เทียบกับ **Cut Power ที่รวมตัวคูณรอบแล้ว** (ยิ่งเลเวลรอบสูง ยิ่งปลดต้นใหญ่ได้ระหว่าง Run) — ต้นระดับ 1 ฟันได้เสมอทุกโซน
3. หน้าตาต้นไม้เปลี่ยนตามธีมโซน (เมเปิล, เห็ด, ซากุระ, ไผ่, สนน้ำแข็ง, คริสตัล, ต้นเมฆ)
4. ต้นระดับ 6 มีราเน่าสีม่วงเรืองแสง ฟันแล้วมีเอฟเฟกต์ "ชำระ" เป็นแสงเขียว
5. ต้นที่พลังไม่ถึง แสดงกุญแจ + "ต้องการ Power xx"
6. ล้มต้นแล้วเกิดใหม่ใน 15 วินาที

#### 4.3.1 ป่าใช้ร่วมกันทั้งเซิร์ฟ (สูงสุด 7 คน)

1. HP ต้นไม้เก็บที่ Server — ทุกคนเห็นต้นเดียวกัน แถบ HP เดียวกัน
2. **ไม่แย่งกัน**: ทุกคนที่ฟันต้นนั้นภายใน 10 วินาทีก่อนล้ม ได้รางวัลเต็ม (EXP/Wood/Coins ของตัวเอง ตามโซน/Rebirth ของตัวเอง) → ช่วยกันฟันได้ประโยชน์ทั้งคู่ ไม่มีขโมยลาสต์ฮิต
3. ใช้ร่วมกับ Friend Boost → ชวนเพื่อนมาฟันด้วยกันคุ้มที่สุด
4. ความหนาแน่นต้นไม้คิดเผื่อ 7 คน + ต้นเกิดใหม่ไว 15 วินาที; ถ้าโซนไหนคนเยอะ ต้นเกิดไวขึ้นอัตโนมัติ (สูงสุด 2 เท่า)
5. **หีบ**: จุดหีบในป่าใช้ร่วมกัน แต่หีบที่โผล่ **เป็นของแต่ละคน** (ทุกคนที่อยู่ใกล้ตอนเคลียร์ได้หีบของตัวเอง) — ไม่มีใครแย่งหีบ
6. **รังไข่**: ใครหยิบก่อนได้ก่อน (ฟีล Steal an Egg) แต่รังเติมไข่ใหม่ทุก 2–3 นาที
7. ผู้เล่นที่ Rebirth ต่างกัน เห็นต้นไม้ต้นเดียวกัน แต่ HP/รางวัลคิดตาม Rebirth ของตัวเอง (แถบ HP บนจอแสดงตามของเรา) — ดาเมจของคนอื่นคิดเป็น % ให้เรา

### 4.4 พลังฟันและตัวคูณ

1. **Cut Power** = Power อาวุธ × ตัวคูณรอบ × บัฟสัตว์ × บัฟ Rebirth × บัฟอื่นๆ (เลขนี้โชว์บน HUD)
2. ตัวคูณรอบ = **1.08^เลเวลรอบ** (รีเซ็ตทุก Run) — เลเวล 30 ≈ ×10
3. EXP ที่ต้องใช้เลเวลถัดไป = 2.5K × 1.25^เลเวล × 100^(โซนที่อยู่−1) — สเกลตามโซน ทำให้ทุกโซนรู้สึกเหมือนกันแต่ตัวเลขใหญ่ขึ้น
4. Critical: โอกาส 10% ดาเมจ ×10
5. ตัวเลขแสดงแบบย่อ K/M/B/T/Qa/Qi/Sx/Sp/Oc/No/Dc, ดาเมจลอย, crit ตัวทองใหญ่, HUD นับวิ่งขึ้น

### 4.5 อาวุธ — 100 ชิ้น ดู `weapons.md`

1. แฟนตาซีไม่จำกัดประเภท 32 แบบ, 5 ความหายาก, 8 ธาตุ, ชื่อท่าเฉพาะ
2. **Item Level**: อาวุธชิ้นเดียวกันดรอปจากโซน N ได้ Power × 100^(N−1) → อาวุธทั้ง 100 ชิ้นใช้ได้ทุกโซน ไม่ต้องทำอาวุธใหม่ทุกโซน (ดูหัวข้อ 14)
3. ลูกเล่นอนิเมะ: ชื่อท่ากลางจอตอน crit, trail สีตามธาตุ, ร่างปลดผนึก (Legendary/Mythic)
4. **ร่างยักษ์ (Giant)** จากหีบ: ขนาด ×3, Power ×5, Area ×2 — โอกาส 0.5% (หีบ Common) ถึง 8% (หีบ Mythic)
5. **หลอมอาวุธ (Fuse)**: อาวุธเดียวกัน 3 ชิ้น → ★ ขึ้น 1 ดาว (สูงสุด ★5, Power +50% ต่อดาว) — ของซ้ำไม่เสียเปล่า

### 4.6 หีบ

1. 5 ระดับ: Common / Rare / Epic / Legendary / Mythic
2. **LEVEL ของหีบ** = เลเวลรอบตอนเก็บ → ยิ่งเลเวลสูง โอกาสได้ของหายากและร่างยักษ์ยิ่งสูง
3. Drop rate หีบ Common (เลเวลต่ำ): Common 70% / Rare 25% / Epic 5%
4. เปิดหีบที่แท่นในหมู่บ้าน มีแอนิเมชันหมุน ได้ร่างยักษ์ → จอสั่น + ประกาศทั้งเซิร์ฟ
5. **หีบฟรี**: หีบรายเวลา (ทุก 15 นาที), หีบเข้ากลุ่ม+กดไลก์, หีบรายวัน

### 4.7 ไข่และสัตว์เลี้ยง (สไตล์ Steal an Egg)

**ได้ไข่จาก 3 ทาง**
1. **รังไข่ในป่า**: มีสัตว์ผู้พิทักษ์เฝ้า — หยิบไข่แล้ว **ต้องวิ่งหนี** ผู้พิทักษ์ไล่ตาม ถ้าโดนจับไข่หล่นคืนรัง ถือไข่อยู่เดินช้าลง 20% วิ่งถึงหินวาร์ปหรือกด End Run ได้ = ได้ไข่
2. **สายพานไข่ในหมู่บ้าน**: ไข่วิ่งผ่านบนสายพาน ซื้อด้วย Coins (ไข่หายากโผล่นานๆ ครั้ง)
3. หีบบางใบมีไข่

**ฟักและเลี้ยง**
1. วางไข่ในตู้ฟักที่ฐาน → นับถอยหลัง (1 นาทีถึงหลายชั่วโมงตามความหายาก) → ได้สัตว์
2. สัตว์ใส่ **คอก** → สร้าง Coins ต่อวินาที (ได้ตอนออฟไลน์ด้วย สูงสุด 8 ชม.)
3. **พกสัตว์ติดตัว 3 ตัว** (อัปเกรดได้ถึง 6) → บัฟ Power / Wood / EXP / ความเร็ว และบางตัวช่วยฟันต้นไม้
4. ความหายากสัตว์: Common → Rare → Epic → Legendary → Mythic → **Secret**
5. Mutation สัตว์: ได้จากการฟักไข่ตอนมีอากาศพิเศษ (Shocked, Frozen, Sakura, Golden, Rainbow, Celestial ฯลฯ) หรือหลอม — เพิ่มรายได้ ×2 ถึง ×10 (หัวข้อ 4.12)
6. หลอมสัตว์ซ้ำ 3 ตัว → ขั้นสูงขึ้น

**ขโมยไข่ในหมู่บ้าน — ระดับกลาง (ArmZ เลือก)**
1. ผู้เล่นคนอื่นเดินเข้าฐานเรา หยิบ **ไข่ที่ยังไม่ฟัก** จากตู้ฟักได้ **ทีละ 1 ใบ** → ถือวิ่งกลับฐานตัวเอง เดินช้าลง 25%, ขี่ Mount/วาร์ปไม่ได้
2. เจ้าของได้ **แจ้งเตือน + ลูกศรชี้ตัวคนขโมย**; ตีโดน 1 ครั้ง → ไข่หล่นกลับที่เดิม
3. **ปุ่มล็อกฐาน**: บาเรียร์ 60 วินาที คูลดาวน์ 2 นาที (อัปเกรดด้วย Wood ให้นานขึ้นได้ถึง 120 วินาที)
4. คนขโมยติดคูลดาวน์ 3 นาทีต่อฐานเดิม (กันโดนรุมฐานเดียว)
5. ไข่ที่ **ฟักไปแล้วเกิน 75%** ขโมยไม่ได้ (ใกล้ฟักแล้วปลอดภัย)
6. ผู้เล่นใหม่มีโล่ 30 นาทีแรก, คน AFK เกิน 10 นาทีได้โล่อัตโนมัติ, เพื่อนกันขโมยไม่ได้ (ตั้งค่าได้), ไข่ที่ซื้อด้วย Robux ขโมยไม่ได้
7. **สัตว์ที่ฟักแล้วขโมยไม่ได้** — เสียได้แค่ไข่
8. กับดัก/สัตว์เฝ้าฐาน อัปเกรดได้ (เพิ่มเกมรับ)
9. ขโมยสำเร็จได้ Coins โบนัสเล็กน้อย + นับในกระดาน "จอมโจรไข่" (ทำให้การขโมยสนุกแต่ไม่โหด)

### 4.8 สวน (สไตล์ Grow a Garden)

1. ทุกฐานมี **แปลงสวน** (เริ่ม 6 ช่อง อัปเกรดได้ถึง 30)
2. **เมล็ด** ได้จากต้นไม้ที่ล้ม (ดรอปสุ่ม), หีบ, ร้านเมล็ด (สต็อกใหม่ทุก 5 นาที เมล็ดหายากโผล่นานๆ ครั้ง)
3. ต้นไม้ที่ปลูกโตตามเวลาจริง (5 นาทีถึง 24 ชม.) โตเต็มแล้ว **ออกผลซ้ำได้เรื่อยๆ** (ผลไม้, ยางไม้, คริสตัล ตามชนิด) → เก็บไปขายเป็น Coins
4. ต้นไม้บางชนิดให้ **บัฟถาวร** ขณะปลูกอยู่ (เช่น +5% EXP ทั้งเซิร์ฟ)
5. **Mutation ผล**: เกิดจากสภาพอากาศ มีมากกว่า 15 แบบ ซ้อนกันได้ และมีคอมโบ (ตั้งแต่ Wet ×2 ไปจนถึง Cosmic ×150) — ดูหัวข้อ 4.12
6. ต้นที่โตเต็มสามารถ **ตัดทิ้ง** ได้ Wood ก้อนใหญ่ + โอกาสได้เมล็ดหายาก
7. รดน้ำ (เครื่องมือบัวรดน้ำ) เร่งโต 10%

### 4.10 Rebirth — "วัฏจักรใหม่"

1. **เงื่อนไข**: Rebirth ครั้งแรกทำได้หลังล้มบอสโซน 4 (ไม่ต้องรอจบเกม) → ครั้งถัดไปต้องล้มบอสโซนลึกขึ้นทีละโซน (ครั้งที่ 2 = โซน 5 … ตั้งแต่ครั้งที่ 5 = โซน 8) + Coins ตามกำหนด (สเกลตามสูตร)
2. **รีเซ็ต**: Coins, Wood, โซนที่ปลดล็อก, อัปเกรดฐาน (ของตกแต่งฐานไม่หาย)
3. **เก็บไว้**: อาวุธ, สัตว์, Gems, Index, ต้นไม้ในสวน, คอสเมติก
4. **ระดับราเน่า (Rot Tier)** = จำนวน Rebirth (R): HP ต้นไม้/บอส, รางวัล และ Item Level ของที่ดรอป **×10^R**
5. **พลังถาวร ×1.5 ต่อครั้ง (ทบต้น)** + **Rebirth Token** ใช้ใน **ต้นไม้ทักษะ** (Auto Cut หักน้อยลงถึง −25%, ช่องสัตว์ +1, หีบเลเวลเริ่มสูงขึ้น, ×2 Wood ทางฟรี ฯลฯ)
6. **ผลจำลอง** (`balance_sim.py`):
   - ช่วงต้นของแต่ละวัฏจักร ของเก่าฟันโซนแรกๆ ได้ไวมาก = ความสะใจตอนเริ่มใหม่
   - ที่โซน 8 อาวุธดีสุดของเก่า (Mythic ★3) ยังพอใช้ได้ถึงประมาณ Rebirth ที่ 3 แล้วต้องหาดรอปใหม่ของวัฏจักรนั้น → **ทุกวัฏจักรมีเป้าหมายใหม่เสมอ**
7. ตามเรื่อง: ราเน่ากลับมา ต้นไม้ทุกโซนมีสีม่วงมากขึ้นตาม Rot Tier, บทพูด NPC เปลี่ยนตามวัฏจักร

### 4.11 เควส, Index, เป้าหมาย

1. **เควสหลัก (เนื้อเรื่อง)**: ลูกศรนำทางบนจอ บอกเป้าถัดไปเสมอ
2. **เควสรายวัน 3 อัน + รายสัปดาห์ 3 อัน**
3. **Index (สมุดสะสม)**: อาวุธ / สัตว์ / ต้นไม้ / Mutation — สะสมครบหมวดได้บัฟถาวร + Gems
4. **ความสำเร็จ (Achievements)** + ฉายาโชว์บนหัว

### 4.12 สภาพอากาศและอีเวนต์ (สไตล์ Grow a Garden)

#### 4.12.1 ทำงานยังไง

1. **ทั้งแมพมีสภาพอากาศเดียวกัน** ปกติฟ้าใส สุ่มเกิดอีเวนต์อากาศ **ทุก 5–8 นาที** แต่ละครั้งนาน 3–10 นาที
2. **ทุกเซิร์ฟตรงกัน**: ตารางอากาศคำนวณจากเวลา UTC (seed เดียวกัน) → "ตอนนี้ฝนตก" เหมือนกันทุกเซิร์ฟ คนคุยกันใน Discord/TikTok ได้ว่ากำลังมีอะไร
3. **พยากรณ์อากาศ**: มุมจอแสดงอากาศตอนนี้ + เวลาที่เหลือ + อากาศถัดไป (อีเวนต์หายากขึ้น "???" จนเริ่ม)
4. ตอนเริ่ม: แบนเนอร์ใหญ่กลางจอ + เสียง + ท้องฟ้า/แสง/หมอกเปลี่ยนจริง + เอฟเฟกต์ (ฝนตก, ฟ้าผ่าลงพื้น, หิมะสะสมบนหลังคา)
5. อากาศมีผล **ทั้ง 3 วง**: ป่า (ฟันต้นไม้), สวน (Mutation ผล), ไข่/สัตว์ (Mutation สัตว์ + ไข่พิเศษ)
6. **Mutation เกิดเฉพาะตอนเราอยู่ในเซิร์ฟ** (ออนไลน์หรือ Auto Cut AFK) → ให้เหตุผลอยากอยู่ในเกมตอนมีอีเวนต์
7. บางโซนมีอากาศประจำ: ทุ่งน้ำแข็งหิมะตกเบาๆ ตลอด, บึงเห็ดหมอกตลอด, ไผ่สายฟ้าฝนปรอยตลอด (อากาศประจำโซนให้ Mutation อ่อนๆ ของโซนนั้น)

#### 4.12.3 Mutation ซ้อนกัน

1. ผลไม้ 1 ลูกมี Mutation ได้หลายอย่างพร้อมกัน
2. **ราคา = ราคาฐาน × สีพิเศษ (Golden ×20 หรือ Rainbow ×50 เลือกค่าสูงสุดอันเดียว) × (1 + ผลรวมของ Mutation อากาศอื่นๆ)**
   - ตัวอย่าง: Golden + Shocked + Wet → ×20 × (1 + 15 + 2) = **×360**
3. **คอมโบพิเศษ**: Wet + Chilled → Frozen, Shocked + Wet → **Electrified** ×40, Celestial + Aurora → **Cosmic** ×150 (หายากสุด)
4. ไอคอน Mutation แสดงบนผลไม้ + ชื่อสีต่างกัน + ใน Index มีหน้าสะสม Mutation
5. สัตว์ใช้หลักเดียวกัน: Mutation สัตว์เพิ่มรายได้ ×2 ถึง ×10 และสัตว์ 1 ตัวมีได้ 1 Mutation

#### 4.12.4 อีเวนต์ใหญ่

1. **พ่อค้าเร่กระรอก**: มาทุก 1 ชม. อยู่ 10 นาที ขายเมล็ด/ไข่/อาวุธหายาก
2. **อีเวนต์สุดสัปดาห์**: เสาร์–อาทิตย์ อีเวนต์หายากเกิดบ่อยขึ้น 2 เท่า
3. **อีเวนต์ตามเทศกาล** (อัปเดตตามซีซัน มีของสะสมเฉพาะ):
   - สงกรานต์: ฝนตกทั้งวัน + ปืนฉีดน้ำ + Mutation **Splash**
   - ฮาโลวีน: Bloodmoon ทุกคืน + ฟักทองยักษ์ให้ฟัน
   - คริสต์มาส/ปีใหม่: หิมะทั้งแมพ + ต้นสนของขวัญ
   - ลอยกระทง: ออโรรา + โคมลอยบนท้องฟ้า
4. **Live Event (ผู้สร้างออนไลน์)**: ArmZ กดเปิดจากแผงแอดมิน → ทุกเซิร์ฟพร้อมกัน ปล่อยอากาศหายากติดกันหลายรอบ (ฟีล "Admin Abuse" ของ Grow a Garden) ประกาศล่วงหน้าใน Discord/Group ให้คนเข้าเกมพร้อมกัน

#### 4.12.5 Balance ของอากาศ

1. สัดส่วนเวลา: ฟ้าใสประมาณ 50%, อากาศธรรมดา 40%, อากาศหายาก 10%
2. เป้า: อากาศเพิ่มรายได้สวนเฉลี่ยประมาณ **+20–30%** สำหรับคนที่อยู่ในเกม — ส่วนใหญ่มาจากโอกาสลุ้น Mutation ใหญ่นานๆ ครั้ง
3. ผลต่อป่าเป็นบัฟสั้นๆ ไม่เปลี่ยนสูตรหลัก (หัวข้อ 14) — ไม่ทำให้ Balance พัง
4. ราคา Mutation ใหญ่มีเพดานต่อวัน (เช่น ขาย Cosmic ได้ราคาเต็ม 5 ลูกแรก) กันเงินเฟ้อ

#### 4.12.6 รองรับเพิ่มอากาศใหม่

1. อากาศแต่ละแบบเป็นแถวใน `Config.Weather` (ชื่อ, ความถี่, เวลา, ผล, Mutation, Preset แสง/VFX/เสียง)
2. Mutation เป็นแถวใน `Config.Mutations` (ค่าคูณ, คอมโบ, ไอคอน, สี)
3. เพิ่มอากาศใหม่ = เพิ่มแถว + ทำ VFX → `WeatherService` สุ่มเข้าตารางเอง
4. อีเวนต์เทศกาลตั้งวันเริ่ม/จบล่วงหน้าใน `Config.Events`

### 4.13 Leaderboard, Daily, Codes

1. **Leaderboard** (ในหมู่บ้าน + Global): ต้นไม้ที่ฟันรวม, ดาเมจสูงสุดต่อครั้ง, Rebirth, รายได้ต่อวินาที, แรงก์ PvP
2. **Daily Reward**: ล็อกอินติดกัน 7 วัน วันที่ 7 ได้หีบใหญ่ ขาดแล้วเริ่มใหม่
3. **Codes**: ช่องกรอกโค้ดในเมนู ให้ Gems/หีบ/บัฟ ตั้งโค้ดเวลาอัปเดตหรือยอดไลก์ถึงเป้า

### 4.14 PvP — แมพแยก "Chop Arena"

1. Place แยกใน Universe เดียวกัน เข้าผ่านพอร์ทัลในหมู่บ้าน (TeleportService + ห้องรอจับคู่)
2. **ระบบต่อสู้**: ตีธรรมดา, ตีหนัก (ชาร์จ), **ท่าเฉพาะอาวุธ** (ชื่อท่าตาม weapons.md, คูลดาวน์), พุ่งหลบ (Dash), บล็อก
3. **โหมด**
   - **Duel 1v1**
   - **Free-for-All** สูงสุด 7 คน
   - **Timber Clash (ทีม)**: 2 ทีมแข่งกันฟันต้นไม้ยักษ์กลางสนาม ตีกันขัดขวางได้ ทีมที่ล้มก่อนชนะ
   - **Egg Heist (ทีม)**: แย่งไข่กลางสนามไปส่งฐานตัวเอง (ฟีล Steal an Egg)
4. **ความยุติธรรม**
   - **Ranked**: ปรับค่าสถานะทุกคนให้เท่ากัน อาวุธต่างกันแค่สไตล์ท่า → ชนะด้วยฝีมือ
   - **Casual**: ใช้พลังจริงแต่มีเพดานกันเก่งเกิน
5. แรงก์: Wood → Bronze → Silver → Gold → Diamond → Mythic, รีเซ็ตทุกซีซัน (1 เดือน)
6. รางวัล: Arena Tokens → สกินอาวุธ, เอฟเฟกต์, ฉายา (**ไม่ให้พลัง** เพื่อไม่ให้ PvP บังคับต้องเล่น)

## 5. ทำให้รู้สึก "ไปข้างหน้าตลอด"

1. **แถบเป้าหมายถัดไป** บนจอเสมอ เช่น "อีก 23% ถึงโซนถัดไป"
2. **ลูกศรนำทาง** ไปเควสหลัก ผู้เล่นไม่มีวันหลงว่าต้องทำอะไร
3. ทุก Run ได้ของติดมือแน่นอน (หีบอย่างน้อย 1 ใบ, เมล็ด, EXP)
4. **ระหว่างรอก็มีความคืบหน้า**: สวนโต, ไข่ฟัก, สัตว์สร้างเงิน, รายได้ออฟไลน์
5. เป้าระยะสั้น/กลาง/ยาวซ้อนกัน: เลเวลรอบ (นาที) → เควสรายวัน (ชั่วโมง) → บอสโซน (วัน) → Rebirth (สัปดาห์) → Index ครบ (เดือน)
6. แจ้งเตือน "เกือบได้แล้ว": "ไข่ฟักในอีก 30 วิ", "อีก 1 ชิ้นหลอม ★3 ได้"
7. ปลดล็อกฟีเจอร์ทีละอย่างตามบทเนื้อเรื่อง ไม่โยนทุกอย่างใส่ตั้งแต่แรก
8. ของซ้ำไม่เสียเปล่า (Fuse อาวุธ/สัตว์, Index)

2. ของตกแต่งซื้อด้วย **Wood** (ใช้ Wood ที่เหลือให้มีค่าตลอด) + ชุดพิเศษปลดจากเนื้อเรื่องแต่ละโซน (ชุดเมเปิล, ชุดซากุระ, ชุดน้ำแข็ง ฯลฯ)
3. หมวด: รั้ว, ทางเดิน, โคมไฟ, ต้นไม้ประดับ, ป้าย, บ้านพัก, ของจากบอส (ถ้วยรางวัล)
4. **คะแนนความสวยฐาน** → ไลก์จากผู้เล่นอื่น + กระดานผู้นำ "ฐานยอดนิยม"
5. ของตกแต่ง **ไม่ให้พลัง** (กันบังคับต้องซื้อ) — ยกเว้นกับดักกันขโมยที่เป็นหมวดแยก

### 9.3 สัตว์ขี่ (Mount)

1. สัตว์บางสายพันธุ์ (ติดแท็ก Rideable) ขี่ได้ เช่น หมาป่า, กวาง, นกยักษ์, มังกรน้อย
2. ความเร็วตามความหายาก: Common ×1.3 → Mythic ×2.5, บางตัวกระโดดสูง/ร่อนได้ (เหมาะกับแมพกว้าง)
3. ขี่ระหว่าง Run ได้ ลงจากหลังอัตโนมัติตอนฟัน
4. ขี่ตอนถือไข่ที่ขโมยมา**ไม่ได้** (กันขโมยแล้วหนีง่ายเกินไป)
5. ปลดล็อกการขี่ครั้งแรกจากเนื้อเรื่องบท 2 (แผนที่ใหญ่ขึ้นพอดีตอนนั้น)

### 9.4 Photo / Emote

1. **วงล้อท่าทาง** (กดปุ่มเดียว): เต้น, โบกมือ, นั่ง, **ท่าโชว์อาวุธ** แบบอนิเมะ (หมุนอาวุธ + ออร่าตามธาตุ)
2. อาวุธ Legendary/Mythic มีท่าโชว์เฉพาะตัว
3. **โหมดถ่ายรูป**: ซ่อน UI, กล้องอิสระ, ฟิลเตอร์ (อนิเมะ, ซีเปีย, กลางคืน), ใส่กรอบชื่อเกม
4. ท่าทางได้จากหีบ, เควส, PvP, Season Pass และร้านคอสเมติก

## 14. แผน Balance — สูตรเดียวทั้งเกม

### 14.1 หลักการ

1. ทุกค่าของโซน N = ค่าโซน 1 × **ZoneScale(N) = 100^(N−1)** — HP, EXP, Wood, Coins, Power ขั้นต่ำ, Power อาวุธที่ดรอป, ราคาเมล็ด/ไข่
2. ผลคือ **ทุกโซนเล่นแล้วรู้สึกเหมือนกัน แต่ตัวเลขใหญ่ขึ้น ×100** → เพิ่มโซนใหม่กี่โซนก็ไม่ต้องจูนใหม่ทั้งเกม
3. ความหายากของอาวุธครอบคลุมพอดี 1 โซน: Common → Mythic = ×100 → **Mythic ของโซน N ≈ อาวุธดีของโซน N+1** ทำให้มีเป้าหมายข้ามโซนตลอด

### 14.2 แหล่งพลังทั้งหมด

| แหล่ง | ช่วงค่า | ทำหน้าที่ |
|---|---|---|
| ความหายากอาวุธ | ×1 / ×3 / ×10 / ×32 / ×100 | ไต่ภายในโซน |
| สุ่มค่าในความหายาก | ×1 – ×4 | ลุ้นตอนเปิดหีบ |
| **Item Level** (โซนที่ดรอป) | ×100 ต่อโซน | ข้ามโซน |
| ตัวคูณรอบ 1.08^เลเวล | ×1 → ประมาณ ×10 ใน 10 นาที | ความมันระหว่าง Run |
| ดาว Fuse ★1–★5 | ×1 – ×3 | ใช้ของซ้ำ |
| ร่างยักษ์ (Giant) | ×5 | ลุ้นของหายาก |
| สัตว์เลี้ยง | ×1.2 ต่อโซน + ความหายากสัตว์ | ระบบไข่ส่งผลต่อการฟัน |
| Rebirth | พลัง ×1.5 ต่อครั้ง (ทบต้น) แต่ราเน่า ×10 ต่อครั้ง | เล่นยาว ต้องหาของใหม่ทุกวัฏจักร |
| Critical | 10% × 10 (เฉลี่ย ×1.9) | ตัวเลขเด้ง |

### 14.3 ผลจำลอง (`balance_sim.py`, Run 10 นาที)

| ผู้เล่น | ผลในโซนนั้น |
|---|---|
| เริ่มเกม (อาวุธเริ่มต้น) | ต้นระดับ 1 → 2 ช้าไป → **แก้: Run แรกการันตีหีบ Rare 1 ใบ** |
| เข้าโซนใหม่ด้วย Legendary ของโซนก่อน | เริ่มที่ต้นระดับ 1 ไต่ถึงระดับ 2–4 |
| เข้าโซนใหม่ด้วย Mythic ของโซนก่อน | เริ่มระดับ 2 → ถึงระดับ 6 ใน 10 นาที (โค้งที่ดีที่สุด) |
| Rare ★2 ของโซนนี้ | ฟันระดับ 6 ได้ภายใน 1 นาที |
| Epic / Legendary ของโซนนี้ | ฟันทีเดียวล้มทุกต้น → สัญญาณ "ไปโซนต่อไปได้แล้ว" |

1. ผลเหมือนกันทุกโซน (ต่างแค่หลักตัวเลข) = สูตรใช้ได้
2. เป้าหมายจริง (ยืนยันตอนทดสอบกับคน): โซนแรกประมาณ 30 นาที แล้วแต่ละโซนนานขึ้นทีละนิด
3. ฟันกี่ครั้งถึงล้มอยู่ที่ 1–5 ครั้ง ตามสไตล์ Cut Trees ที่ฟันไวๆ หลายต้น

### 14.4 ค่าอื่นๆ ที่ผูกกับสูตร

1. **บอสโซน** HP = ต้นระดับ 6 ของโซน × 200 → ใช้เวลาประมาณ 1–2 นาทีด้วย Epic ของโซน ตีด้วยกันได้หลายคน
2. **ราคาเมล็ด/ไข่** = ราคาโซน 1 × ZoneScale ของโซนที่ขาย
3. **รายได้สัตว์/สวน** สเกลตามโซนที่ไข่/เมล็ดมาจาก

### 14.5 เพดานตัวเลข

1. Roblox ใช้ number แบบ double เก็บได้ถึงประมาณ 1e308
2. ×100 ต่อโซน และ ×10 ต่อ Rebirth → 8 โซนรองรับ Rebirth ได้ประมาณ **280 ครั้ง** (หรือโซนเพิ่มได้ถึงประมาณ 140 โซน) ก่อนชนเพดาน
3. ตัวย่อหลักสร้างอัตโนมัติต่อจาก Dc (UDc, DDc, …) แล้วค่อยเป็น `1.2e150`
4. ถ้าวันหนึ่งเกินจริง ค่อยเปลี่ยนเป็น BigNum (เก็บ mantissa + exponent) — ทุกที่เรียกผ่าน `NumberFormat` อยู่แล้ว จึงแก้จุดเดียว

### 14.6 กฎเวลาเพิ่มของใหม่

1. อาวุธใหม่: เลือกความหายาก → Power อยู่ในช่วงของความหายากนั้น (×1–×4 ของค่าฐาน) — ไม่ต้องคิดเลขเอง
2. โซนใหม่: เพิ่ม 1 แถวใน Config → ตัวเลขคำนวณเองจากสูตร
3. แก้ตัวเลขอะไรก็ตาม → รัน `balance_sim.py` ดูว่าโค้งยังดีอยู่

## 15. รองรับการเพิ่มของในอนาคต

### 15.1 ทุกอย่างเป็นข้อมูล (Data-driven Registry)

1. `ReplicatedStorage.Config` แยกไฟล์ละหมวด: Zones, Trees, Weapons, Chests, Eggs, Pets, Seeds, Mutations, Weather, Quests, Story, Events, Codes, Shop
2. ระบบทุกตัวอ่านจาก Config → **เพิ่มของใหม่ = เพิ่มแถวข้อมูล + โมเดล** ไม่ต้องแก้โค้ด
3. ตัวอย่างแถวอาวุธ: `{ id = "wpn_bent_halberd", rarity = "Common", element = nil, basePower = 125, speed = 1.2, area = 5, model = "BentHalberd" }`

### 15.2 รหัสถาวร (ID)

1. ทุกของมี `id` ถาวร (เช่น `wpn_bent_halberd`) แยกจากชื่อที่โชว์ → เปลี่ยนชื่อ/แปลภาษาได้ เซฟผู้เล่นไม่พัง
2. **ห้ามลบหรือเปลี่ยน id** — ของที่เลิกใช้ใส่ `retired = true` (ไม่ดรอปแล้วแต่คนที่มีอยู่ยังใช้ได้)

### 15.3 ระบบเซฟ

1. ใช้ **ProfileStore** (โมดูลชุมชนยอดนิยม) — มี Session Lock กันของซ้ำ (dupe) ซึ่งสำคัญมากเพราะเกมมีการขโมย
2. เซฟเฉพาะ id + จำนวน + Item Level + ดาว (ไม่เซฟค่าที่คำนวณได้)
3. มี `DataVersion` + รายการ Migration → อัปเดตเกมแล้วเซฟเก่าแปลงอัตโนมัติ
4. ฟิลด์ใหม่เติมค่าเริ่มต้นให้คนเก่าเอง (Reconcile)

### 15.4 แมพต่อเติมได้

1. ทุกโซนใช้ **แม่แบบเดียวกัน** (ชื่อโฟลเดอร์ + Tags ตามหัวข้อ 6) → `ZoneService` หาโซนจาก Tag เอง เพิ่มโซนแล้วระบบรู้จักทันที
2. บนเกาะลอยฟ้า (โซน 8) เว้น **"ประตูมิติ" (Realm Gate)** ไว้ → อนาคตเพิ่ม **Realm 2, 3, …** เป็นพื้นที่ใหม่ (อวกาศ, ใต้ทะเล, ปรโลก ฯลฯ) และทวีปยังต่อโซนเพิ่มทางเหนือ/ตะวันออกได้โดยไม่ต้องรื้อของเดิม
3. หมู่บ้านเว้นที่ว่างไว้สำหรับร้าน/NPC ใหม่
4. PvP เป็น Place แยก → เพิ่มโหมด/แผนที่ Arena ได้อิสระ

### 15.5 Feature Flags + LiveOps

1. `Config.Features` เปิด/ปิดระบบได้ (เช่น ปิดการขโมยชั่วคราว, เปิด PvP ทีหลัง) → ปล่อยของทีละอย่างได้
2. อีเวนต์มีเวลาเริ่ม/จบ (UTC) ตั้งล่วงหน้าได้
3. Codes มีวันหมดอายุ
4. ร้าน/สายพานไข่ใช้ตารางสุ่มใน Config → หมุนของตามซีซันได้

### 15.6 โครงโค้ด

1. ทุกระบบเป็นโมดูล Service ที่มี `Init` / `Start` → ระบบใหม่ = โมดูลใหม่ ไม่ไปแก้ของเดิม
2. ฝั่ง UI ทำเป็นชิ้นส่วนใช้ซ้ำ: กรอบความหายาก, การ์ดไอเทม, ตัวเลขนับวิ่ง, ปุ่ม → ของประเภทใหม่ใช้ชิ้นเดิม
3. ตัวเลขทุกตัวผ่าน `NumberFormat` และทุกสูตรผ่าน `Balance` module เดียว (ตรงกับ `balance_sim.py`)

## 17. เติมเงินแบบไม่ Pay-to-win — "สายฟรีก็เทพได้ สายเติมเทพไวขึ้น"

### 17.1 กฎเหล็ก

1. **ทุกอย่างที่ให้พลัง ต้องหาได้ฟรีในเกม** — เงินจริงแค่ทำให้ไวขึ้น ไม่ใช่ได้ของที่สายฟรีไม่มีวันได้
2. **ของ Exclusive ที่ซื้ออย่างเดียว = คอสเมติกเท่านั้น** (สกิน, ออร่า, trail, ท่าทาง, ของตกแต่ง, ฉายา)
3. **Auto Cut ฟรีทุกคน** และการลดหัก Auto Cut ทำได้ทางเดียวคือต้นไม้ทักษะ Rebirth
4. **PvP Ranked ปรับค่าสถานะเท่ากัน** → เงินจริงไม่มีผลกับการชนะ PvP
5. **ไข่ที่ซื้อด้วย Robux ขโมยไม่ได้** (เข้าตู้ฟักแบบปลอดภัยทันที) — กันคนจ่ายเงินแล้วโดนขโมยจนเลิกเล่น
6. **บูสต์ทุกชนิดมีเพดานรวม** (เช่น บูสต์ซ้อนกันสูงสุด ×4) กันตัวเลขพังและกันสายเติมทิ้งห่างเกินไป
7. ไม่มีกาชาที่ต้องจ่าย Robux ตรงๆ เพื่อสุ่มพลัง — สุ่มหีบใช้ Gems/กุญแจที่หาฟรีได้ด้วย
8. **Game Pass กับทางฟรีไม่ทับกัน**: บูสต์ถาวรประเภทเดียวกัน (เช่น ×2 Wood) ใช้ค่าที่ดีที่สุดค่าเดียว ไม่คูณซ้อน → ปลายทางสายฟรีกับสายเติม**เท่ากันจริง** สายเติมแค่ได้ตั้งแต่วันแรก (ช่องสัตว์ก็เพดาน 6 ช่องเหมือนกัน)

## 18. Admin Panel — ทดสอบทุกอย่างในเกม

### 18.1 เปิดยังไง / ใครใช้ได้

1. **ผู้เล่นที่มียศ Admin ขึ้นไปจะเห็นปุ่ม "ADMIN" สีเหลือง (ไอคอนโล่) ที่มุมซ้ายล่างของจอ** — คนทั่วไปไม่เห็นปุ่มนี้เลย
2. กดปุ่ม ADMIN (หรือ **F2** บนคอม) → หน้าต่าง Admin Panel เปิดกลางจอ กดปุ่ม X หรือ F2 อีกครั้งเพื่อปิด
3. **ใช้ด้วยการกดล้วนๆ** ไม่ต้องพิมพ์อะไร — ช่องพิมพ์คำสั่ง (เช่น `/give coins 1e15 me`) มีไว้เป็นทางเลือกสำหรับคนพิมพ์ไวเท่านั้น
3. **สิทธิ์**: เช็คที่ Server เท่านั้น จากรายชื่อ UserId ใน `Config.Admins` (+ ยศในกลุ่ม Roblox ถ้ามีกลุ่ม) — ฝั่ง Client แค่แสดงผล กดปุ่มอะไรก็ต้องผ่าน Server ตรวจสิทธิ์ก่อน
4. **ยศ Admin** มาจาก (เช็คทั้งสองทาง): รายชื่อ UserId ใน `Config.Admins` หรือ **ยศในกลุ่ม Roblox** ของเกม (เช่น ยศ 200+ = Admin, 250+ = Owner) → ตั้งยศให้ทีมงานในกลุ่มได้เลยไม่ต้องอัปเดตเกม
5. ระดับสิทธิ์:

| ระดับ | ทำอะไรได้ |
|---|---|
| **Owner** (ArmZ) | ทุกอย่าง รวมถึงลบเซฟ, Live Event ทุกเซิร์ฟ, ตั้งแอดมินคนอื่น |
| **Admin** | เสกของ, เปลี่ยนอากาศ, ทดสอบระบบ เฉพาะในเซิร์ฟตัวเอง |
| **Moderator** | เตะ/แบน/เตือน/ส่องผู้เล่น — เสกของไม่ได้ |
| **Tester** | ใช้ได้เฉพาะในเซิร์ฟทดสอบ / Studio |

6. **ใน Studio** ทุกคนเป็น Owner อัตโนมัติ (ทดสอบง่าย) — ในเกมจริงต้องอยู่ในรายชื่อเท่านั้น
7. **ไอดีที่ไม่มีสิทธิ์จะไม่ได้โหลด UI Admin เลย** (ไม่ส่งไปฝั่ง Client) กันคนแกะเกม

### 18.1.1 หน้าตา UI (ดู Mockup: Artifact "Chop a Tree Admin Panel")

1. **สไตล์เดียวกับ UI เกม** (ตามรูปตัวอย่างของ ArmZ): ปุ่มใหญ่ ขอบดำหนา มุมมน เงาด้านล่าง สีสด ตัวหนังสือไทยฟอนต์ Mitr
2. **โครงหน้าต่าง (คอม)**:
   - แถบบน: ชื่อ ADMIN PANEL + ป้ายยศ (OWNER/ADMIN/MOD) + ปุ่มเลือกเป้าหมาย **ตัวเอง / เลือกผู้เล่น / ทุกคน** + ปุ่มปิด
   - ซ้าย: รายการแท็บแนวตั้ง 17 แท็บ แต่ละแท็บมีจุดสีประจำหมวด แท็บที่เลือกเป็นสีเหลือง
   - ขวา: เนื้อหาแท็บ เป็นปุ่มใหญ่เรียงเป็นตาราง กดครั้งเดียวทำงาน
   - ล่าง: แถบแจ้งผล "ทำแล้ว: ... → ใคร" ทุกครั้งที่กด
3. **แท็บแรก "ปุ่มลัด"**: 9 ปุ่มใหญ่ที่ใช้บ่อยที่สุด (รวยทันที, เลเวลรอบ 50, หีบ Mythic ×10, ปลดทุกโซน, โตทันทีทั้งสวน, ฟักไข่ทันที, ฝนดาวตก, Rebirth ทันที, ฆ่าต้นไม้ทั้งโซน) + แถว **คำสั่งโปรด** (ชุดคำสั่งหลายอย่างกดทีเดียว)
4. **แท็บเงิน**: เลือกจำนวนจากปุ่ม (1K / 1M / 1B / 1T / 1Qa / 1Qi) → แต่ละสกุลเงินมีปุ่ม **+ เสก / ตั้งค่า / เป็น 0** + ค่าปัจจุบันโชว์สด
5. **แท็บอาวุธ**: ปุ่มกรองความหายาก → การ์ดอาวุธ (กดเลือก) → แผงขวาเลือก Item Level 1–8, ดาว ★1–★5, ร่างยักษ์ → **โชว์ Power ที่จะได้ทันที** → ปุ่ม เสกเข้ากระเป๋า / เสก + ถือทันที
6. **แท็บอากาศ**: ช่องอากาศทั้ง 13 แบบ (สีตามอากาศ) → เลือกระยะเวลา → เริ่มเลย / หยุด + กล่อง Live Event ทุกเซิร์ฟ (ยืนยัน 2 ชั้น)
7. **แท็บอื่น**: ตารางปุ่มใหญ่ 3 คอลัมน์ ปุ่มอันตราย (แบน, เตะ, ลบเซฟ) เป็น**สีแดงเสมอ**
8. **มือถือ (แนวนอน)**: หน้าต่างเต็มจอ แท็บเป็นแถบเลื่อนแนวนอนด้านบน ปุ่มลัด 4×2 ขนาดใหญ่ (ปุ่มทุกอันสูงอย่างน้อย 44px กดง่ายด้วยนิ้ว)
9. ปุ่มทุกอันต้องมี feedback: กดแล้วยุบลง + เสียงคลิก + แถบแจ้งผล

### 18.2 เลือกเป้าหมาย

1. ทุกคำสั่งเลือกเป้าหมายได้: **ตัวเอง / ผู้เล่นที่เลือก (รายชื่อในเซิร์ฟ + ค้นชื่อ) / ทุกคนในเซิร์ฟ**
2. ช่องตัวเลขพิมพ์แบบย่อได้: `1.5K`, `3M`, `2Qa`, `1e30` + ปุ่มลัด (+1K, +1M, +1B, ×10, MAX, ตั้งเป็น 0)
3. ปุ่ม **"ทำซ้ำคำสั่งล่าสุด"** และ **ชุดคำสั่งโปรด** (บันทึกไว้กดทีเดียว)

### 18.3 แท็บทั้งหมด

**แท็บ 1 — ผู้เล่น**
1. ดูข้อมูลสด: Coins, Wood, Gems, EXP, เลเวลรอบ, ตัวคูณ, Cut Power, โซน, Rebirth, บัฟที่ติดอยู่ทั้งหมด (พร้อมที่มาของแต่ละตัวคูณ)
2. ความเร็วเดิน/กระโดด, บินได้ (Fly), ทะลุกำแพง (Noclip), อมตะ (God mode), มองไม่เห็น
3. วาร์ป: ไปหาผู้เล่น / ดึงผู้เล่นมาหา / ไปโซน 1–8 / หมู่บ้าน / ลานบอส / Realm Gate / จุดที่คลิก
4. Respawn, รีเซ็ตตัวละคร

**แท็บ 2 — เงินและค่าสถานะ**
1. เสก/ตั้งค่า/ลบ: **Coins, Wood, Gems, Arena Tokens, เศษดาว, Rebirth Token**

3. ตั้ง Cut Power ชั่วคราว (override) เพื่อทดสอบต้นไม้แต่ละระดับ
4. ปุ่ม "รวยทันที" (ตั้งทุกสกุลเงินเป็นค่ามหาศาล) และ "จนทันที" (เป็น 0)

**แท็บ 3 — อาวุธ**
1. รายการอาวุธทั้ง 100 ชิ้น ค้นหาด้วยชื่อ/ID, กรองตามความหายาก/ธาตุ/ประเภท, มีรูปพรีวิว

3. ปุ่ม: เสกเข้ากระเป๋า, เสกแล้ว Equip ทันที, เสกทุกชิ้นในความหายากนี้, เสกครบ 100 ชิ้น

5. ลบอาวุธ / ล้างกระเป๋า

**แท็บ 4 — หีบ**
1. เสกหีบทุกระดับ (Common–Mythic) พร้อมตั้ง **LEVEL** และจำนวน → เข้ารายการหีบบน RunPanel
2. เปิดหีบทันที / เปิดแบบดูแอนิเมชัน / **บังคับผล** (เลือกอาวุธที่จะได้ + บังคับร่างยักษ์) เพื่อทดสอบแอนิเมชันหายาก
3. **ทดสอบอัตราดรอป**: เปิดจำลอง 10,000 ใบ (ไม่ให้ของจริง) → แสดงตารางผลเทียบกับอัตราใน Config
4. ล้างรายการหีบ

**แท็บ 5 — ไข่และสัตว์**
1. เสกไข่ทุกชนิด (รวม Secret) → เข้าตู้ฟัก, ฟักทันที, ตั้งเวลาฟักเหลือ X วินาที
2. เสกสัตว์ทุกตัว พร้อมเลือก **Mutation** และขั้นหลอม
3. ทดสอบ Mount: เสกสัตว์ขี่ได้แล้วขึ้นขี่ทันที
4. **ทดสอบขโมย**: เสก NPC หุ่นขโมย (บอท) วิ่งมาขโมยไข่ฐานเรา / ให้เราเป็นคนขโมยฐานบอท, ปิด-เปิดโล่, รีเซ็ตคูลดาวน์ล็อกฐาน
5. เปิด/ปิดโล่ผู้เล่นใหม่, โล่ AFK

**แท็บ 6 — สวน**
1. เสกเมล็ดทุกชนิด, ปลูกเต็มแปลงทันที
2. **โตทันที** (ทั้งแปลง/ต้นที่เลือก), เร่งเวลา ×10 / ×100
3. ใส่ **Mutation** ให้ผลไม้ (เลือกหลายอันพร้อมกัน) → เช็คสูตรราคาซ้อน
4. รีสต็อกร้านเมล็ดทันที, บังคับให้เมล็ดหายากขึ้นร้าน
5. อัปเกรดแปลงเต็ม / รีเซ็ตแปลง

**แท็บ 7 — ป่าและ Run**
1. เริ่ม/จบ Run, ตั้งเลเวลรอบ, เปิด/ปิด Auto Attack / Auto Cut
2. **ฆ่าต้นไม้ทั้งโซน**, เกิดต้นไม้ใหม่ทันที, เสกต้นไม้ระดับที่เลือกตรงหน้า
3. แสดง HP/Power ขั้นต่ำเหนือต้นไม้ทุกต้น (Debug overlay)
4. **ทดสอบ Auto Cut แบบเร่งเวลา**: จำลอง AFK 1 ชม. แล้วสรุปว่าได้อะไร เทียบกับเล่นเอง
5. เสกบอสโซน/บอสโลก, ตั้ง HP บอสเหลือ 1%, ฆ่าบอสทันที

**แท็บ 8 — โซน, เนื้อเรื่อง, เควส**
1. ปลดล็อก/ล็อกโซนใดก็ได้, เปิดประตูราเน่า
2. ข้ามไปบทเนื้อเรื่องไหนก็ได้, เล่นคัตซีนซ้ำ, รีเซ็ตเนื้อเรื่อง
3. ทำเควสเสร็จทันที / รีเซ็ตเควสรายวัน-รายสัปดาห์
4. ปลด Index ทั้งหมด / รีเซ็ต Index, ปลด Achievement

**แท็บ 9 — อากาศและอีเวนต์**
1. **บังคับอากาศ** ได้ทุกแบบ (ฝน, ฟ้าผ่า, หิมะ, หมอก, ลม, ซากุระ, แสงทอง, ดาวตก, ออโรรา, Bloodmoon, รุ้ง, ราเน่าบุก) + ตั้งเวลานาน
2. หยุดอากาศ / ข้ามไปอากาศถัดไป / ดูตารางอากาศ 24 ชม. ข้างหน้า
3. เปลี่ยนเวลาในเกม (กลางวัน/กลางคืน)
4. เรียกพ่อค้าเร่ทันที, เปิดอีเวนต์เทศกาล (สงกรานต์/ฮาโลวีน ฯลฯ) ล่วงหน้าเพื่อทดสอบ
5. **Live Event** (Owner เท่านั้น): ตั้งรายการอากาศต่อเนื่อง → ปล่อย**ทุกเซิร์ฟพร้อมกัน** + ข้อความประกาศ

**แท็บ 10 — Rebirth**
1. Rebirth ทันที (ข้ามเงื่อนไข), ตั้งจำนวน Rebirth ตรงๆ (ดู Rot Tier)
2. เพิ่ม Rebirth Token, ปลดต้นไม้ทักษะทั้งหมด / รีเซ็ต

**แท็บ 11 — ร้านและเติมเงิน (ทดสอบไม่เสีย Robux)**
1. ให้/ลบ **Game Pass** แต่ละตัว (เฉพาะในระบบเกม ไม่ใช่ Roblox จริง) → ทดสอบผล
2. **จำลองการซื้อ Dev Product** ทุกตัว (ยา, Gems, บูสต์ทั้งเซิร์ฟ) ผ่าน flow เดียวกับของจริง
3. เปิด/ปิด Season Pass Premium, ตั้งเลเวล Pass
4. ทดสอบว่า Game Pass กับทางฟรี **ไม่ทับกัน** (แสดงค่าบูสต์สุดท้าย)

**แท็บ 12 — PvP**
1. สร้างห้องทดสอบ, เสกบอทคู่ซ้อม (ยืนเฉย/ตีกลับ/หลบ)
2. ตั้งแรงก์/Arena Tokens, จบซีซันทันที
3. เปิดดูค่าที่ถูกปรับเท่ากันในโหมด Ranked

**แท็บ 13 — Balance สด**
1. แก้ค่าสูตรหลักชั่วคราว (ZoneScale, ตัวคูณรอบ, EXP, ดรอป, Auto Cut, Rot) **ในเซิร์ฟนี้เท่านั้น** → เห็นผลทันทีไม่ต้องอัปเดตเกม
2. ปุ่ม "คืนค่าเดิม" และ "คัดลอกค่าไปใส่ Config" (เอาค่าที่จูนแล้วไปใส่ repo)
3. ตัวจับเวลา: วัดว่าใช้กี่นาทีถึงต้นระดับ X / โซนถัดไป (เทียบกับผล `balance_sim.py`)

**แท็บ 14 — ข้อมูลเซฟ (Data)**
1. ดูเซฟของผู้เล่นแบบโครงสร้าง (อ่านง่าย) + ค้นหา
2. บันทึกทันที, โหลดใหม่, **สำรองเซฟ** / **คืนเซฟจากสำรอง**
3. รีเซ็ตเซฟ (ต้องพิมพ์ยืนยัน) — Owner เท่านั้น
4. ทดสอบ Migration: โหลดเซฟเวอร์ชันเก่าตัวอย่างแล้วดูว่าแปลงถูกไหม
5. Export/Import เซฟเป็นข้อความ JSON (ก๊อปเซฟจากเกมจริงมาทดสอบใน Studio)

**แท็บ 15 — จัดการผู้เล่น (Moderation)**
1. ส่อง (Spectate), ดูกระเป๋า/ประวัติ
2. เตือน, เตะ, แบนชั่วคราว/ถาวร (พร้อมเหตุผล), ปลดแบน
3. ยึดของที่ได้จากบั๊ก
4. ประกาศข้อความถึงเซิร์ฟนี้ / ทุกเซิร์ฟ

**แท็บ 16 — Debug**
1. FPS, Ping, หน่วยความจำ, จำนวน Part / ต้นไม้ / NPC ในแต่ละโซน
2. แสดง Hitbox, รัศมี Area, เส้นทาง Pathfinding ของ Auto Cut
3. ดู Log error ล่าสุดของ Server/Client, ตัวนับ Remote ที่ถูกยิงถี่ผิดปกติ (จับโกง)
4. เปิด/ปิด **Feature Flags** ทุกตัวสดๆ
5. ปุ่มทดสอบ UI: แสดงหน้าจอทุกหน้า (สรุป Run, ประกาศของหายาก, Level up ฯลฯ) โดยไม่ต้องเล่นถึง

### 18.4 ความปลอดภัย

1. **ทุกคำสั่งตรวจสิทธิ์ที่ Server** + จำกัดความถี่ — Client ส่งได้แค่ "ขอทำคำสั่ง X" ไม่มีทางสั่งตรง
2. **Log ทุกคำสั่ง** (ใคร, ทำอะไร, กับใคร, เมื่อไหร่) เก็บใน DataStore + ส่ง Discord Webhook (ถ้าต้องการ) → ตรวจย้อนหลังได้
3. ของที่เสกจากแอดมินติดแท็ก `admin_spawned` → **ไม่ขึ้น Leaderboard** และแลก/ขายในระบบที่อาจเปิดอนาคตไม่ได้
4. ผู้เล่นที่โดนแอดมินแก้ค่า จะถูกตัดออกจาก Leaderboard ของซีซันนั้นอัตโนมัติ (กันแอดมินเสกให้เพื่อนขึ้นอันดับ)
5. คำสั่งอันตราย (ลบเซฟ, แบนถาวร, Live Event ทุกเซิร์ฟ) ต้องกดยืนยัน 2 ชั้น
6. Admin Panel อยู่ใต้ Feature Flag ปิดทั้งระบบได้ทันทีถ้าเจอปัญหา

### 18.5 โตไปพร้อมเกม

1. แต่ละแท็บอ่านรายการจาก Config อัตโนมัติ → เพิ่มอาวุธ/สัตว์/อากาศใหม่ ปุ่มเสกขึ้นเองไม่ต้องแก้ Admin Panel
2. ระบบใหม่ทุกตัว (หัวข้อ 15.6) ลงทะเบียนคำสั่งแอดมินของตัวเองผ่าน `AdminService:Register()` → แท็บใหม่โผล่เอง
3. ลำดับการสร้าง: Phase 0 ทำโครง + แท็บ 1, 2, 14, 16 → แต่ละ Phase เพิ่มแท็บของระบบนั้น
