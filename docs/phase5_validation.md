# Phase 5 — ไข่ + สัตว์ + ขโมย + ฐาน (core)

ทำและทดสอบ 2026-10-01 ใน Studio PlaceId `93479990217075`. ไม่ได้ Publish place. ผลตรวจ 81/81 อยู่ใน `phase5_test_results.json`; โค้ดที่เพิ่ม/แก้ 20 ไฟล์ตรง Studio Edit ตาม `phase5_source_checksums.json`.

## ระบบที่ใช้ได้

1. **Config ใหม่**: `Config.Eggs` (ไข่ 4 ชนิด: Meadow/Leaf จากรังโซน 1–2 + Sunburst/Starlit บนสายพาน), `Config.Pets` (สัตว์ 12 ตัว Common→Secret ของโซน 1–2, บัฟ Power/Wood/Exp/Speed, ขี่ได้ 6 ตัว), `Config.Base` (กติกาฐาน/ขโมย/รัง). สูตรร่วม `Shared.PetMath` ใช้ทั้ง server และ UI; โมเดล procedural `Shared.PetVisual`.
2. **PetService** เป็นเจ้าของไข่/ตู้ฟัก/สัตว์/คอก/บัฟ/ขี่/สายพาน. ตู้ฟัก 3 ช่องต่อฐาน ฟักตาม timestamp แม้ออฟไลน์; ไข่ที่เสร็จขณะออนไลน์ช่วงพายุ/หิมะ/แสงทองลุ้น Shocked×3/Frozen×4/Golden×5 (35%) ส่วนเสร็จตอนออฟไลน์ไม่มี mutation. ฟักแล้วเข้าคอกอัตโนมัติถ้ามีที่.
3. **คอก**: สัตว์ในคอกสร้าง Coins/วิ = รายได้ความหายาก (2/6/20/60/200/600) × ZoneScale โซนที่มา × Rot × mutation × (1+0.5×(ขั้น−1)). เงินสะสมในคอกสูงสุด 8 ชม. ทั้งออนไลน์และออฟไลน์ เก็บที่คอกด้วย prompt หรือแท็บฐาน.
4. **พกติดตัว 3 ตัว** (เพดาน 6 ใน Config): บัฟรวมแบบบวก โบนัสความหายาก × 1.2^(โซน−1) × (1+0.25×(ขั้น−1)); Power/Wood/Exp เพดาน ×4, Speed เพดาน ×1.5. Power เข้า `Run.Power` (petMult ของ `Balance.CutPower`), Wood/EXP เข้า `Run.Award`. Client เรนเดอร์สัตว์ตามตัวจาก attribute `PetFollow` (ไม่ replicate โมเดล).
5. **หลอมสัตว์** 3 ตัวชนิด/โซน/Rot/ขั้นเดียวกัน → ขั้น +1 (สูงสุด 5) เก็บ mutation ที่ดีที่สุด. **ปล่อยสัตว์** ต้องกดยืนยันซ้ำใน UI.
6. **Mount**: สัตว์ Rideable ขี่ได้ ความเร็ว Common×1.3 → Mythic/Secret×2.5 (คูณบัฟ Speed). ลงอัตโนมัติเมื่อฟันต้นไม้ (TreeService.Hit) และเมื่อเริ่มถือไข่; ขี่ไม่ได้ขณะถือไข่. เงื่อนไขบทที่ 2 บังคับเมื่อเปิด Feature `Story` (Phase 6).
7. **สายพานไข่**: ไข่ใบใหม่ทุก 20 วิ เห็นพร้อมกัน 3 ใบ คำนวณจาก UTC epoch เหมือนกันทุกเซิร์ฟ; ซื้อได้ใบละครั้งต่อผู้เล่น (บันทึก `Pets.beltBought` ใน profile กันออกเข้าเซิร์ฟ). ราคา = price × ZoneScale(โซนของไข่) และต้องปลดโซนนั้นแล้ว. Client วาดไข่วิ่งบนสายพานตามเวลาเซิร์ฟเวอร์.
8. **รังในป่า (NestService)**: ไข่ 3 จุดต่อรัง (โซน 1–2 รวม 12 จุด) หยิบได้ระหว่าง Run → เดินช้า 20% → ผู้พิทักษ์รัง (หมูป่ามอส) ไล่ เร็ว 15 ใน 4 วิแรกแล้ว 12, ระยะไล่ 90 studs, จับในระยะ 4.5 → ไข่กลับรัง. ถึงหินวาร์ปของโซน (14 studs) หรือกด End Run = ได้ไข่ (`Run.Eggs` → Inventory ตอนจบ Run). ตาย/ออกเกม/จบ Run แบบไม่ใช่ปุ่ม = ไข่กลับรัง. รังเติมใหม่ 2–3 นาที. AutoCut ไม่หยิบไข่ (ต้องกด prompt เอง).
9. **หีบมีไข่**: เปิดหีบมีโอกาส 8% ได้ไข่ของโซนหีบ (เก็บ Rot/admin provenance).
10. **ขโมยไข่ (StealService)**: เดินเข้าตู้ฟักฐานคนอื่น กด prompt (client แสดง "ขโมยไข่") → ถือได้ 1 ใบ เดินช้า 25% ขี่/เริ่ม Run ไม่ได้. ไข่ยังอยู่ใน profile เจ้าของ (`carriedBy`) และหยุดฟักจนกว่าจะส่งถึงฐานตัวเอง (รัศมี 30 studs) จึงย้ายครั้งเดียวแบบไม่มี yield + โบนัส 10% ราคาไข่ + `Stats.EggsStolen`. เจ้าของได้แจ้งเตือน, ไฮไลต์แดง + ลูกศร Beam ชี้คนขโมย และกด E (ReclaimPrompt ระยะ 12) เพื่อทวงคืน. ยกเลิก/ตาย/ออก/เข้า Run → ไข่กลับ. ข้อห้าม: ฟักเกิน 75%, ไข่ Robux (`robux` flag), ฐานล็อก, โล่ผู้เล่นใหม่ 30 นาที (PlaySeconds), โล่ AFK 10 นาที, เพื่อนกัน (ปิดได้ใน `Settings.FriendSteal`), คูลดาวน์ 3 นาทีต่อฐานเดิม. สัตว์ที่ฟักแล้วขโมยไม่ได้.
11. **ล็อกฐาน**: บาเรียร์ ForceField ใช้ `LockBarrier` เดิม 60 วิ (อัปเกรด +20 วิ/เลเวล ถึง 120) คูลดาวน์ 120 วิหลังหมดล็อก. Collision group `BaseBarrierN`/`BaseOwnerN` ให้เจ้าของเดินผ่านได้ คนอื่นที่อยู่ข้างในถูกดันออกตอนล็อก.
12. **อัปเกรดฐานด้วย Wood**: คอก 8→24 ช่อง (+4), ตู้ฟักเร็ว ×1→×2 (+0.25), ล็อก 60→120 วิ; ราคา 1000/1500/2000 × (เลเวล+1)².
13. **UI** (ปุ่ม "ไข่ & สัตว์" ซ้ายใต้ปุ่มสวน): แท็บตู้ฟัก/ไข่/สัตว์/ฐาน/สายพาน, prompt ที่ตู้ฟัก คอก สายพาน เปิดแท็บที่ตรงกัน. แถว/ปุ่มอัปเดตในที่เดิม (ไม่สร้างใหม่ทุก 2 วิ) เพื่อไม่ให้คลิกหายระหว่างรีเฟรช — พบบั๊กนี้ระหว่างทดสอบเมาส์จริงและแก้แล้ว. Summary ตอนจบ Run แสดงจำนวนไข่.
14. **Admin แท็บ "ไข่ & สัตว์"** 20 ปุ่ม: ให้ไข่ทุกชนิด, ไข่เสร็จทันที/เหลือ 5 วิ, ให้สัตว์แต่ละความหายาก, Fox×3 แต่ละ mutation, เสก Wolf แล้วขี่, บอทขโมยไข่ฐานเรา (ทวงคืนด้วย E), สร้าง/ลบฐานบอทให้ขโมย, บังคับเปิด/ปิด/คืนโล่, รีเซ็ตล็อกฐาน/คูลดาวน์ขโมย.
15. **Schema v1 + Reconcile**: `Inventory.Eggs/Pets`, `Pets{incubator,bank,bankAt,beltBought,upgrades,equipSlots}`, `Run.Eggs`, `Stats.EggsHatched/EggsStolen`, `Settings.FriendSteal`. ไม่รีเซ็ตเซฟเดิม. ตอนโหลดล้าง `carriedBy` ที่ค้างจาก crash.
16. Feature `Eggs`/`Stealing` เปิดเป็นค่าเริ่ม; ปิด `Eggs` แล้วบัฟ=1, action ถูกปฏิเสธ, ไข่ที่ถือจากรังกลับรัง.

## ข้อจำกัด/ยังไม่ได้ทำ

1. **ยังไม่ได้ทดสอบขโมยกับผู้เล่นจริงสองบัญชี** — ทดสอบฝั่งคนขโมยด้วยฐานบอท และฝั่งเจ้าของด้วยบอทขโมย. การโอนไข่ข้ามสอง profile ทำในเธรดเดียวไม่มี yield แต่ ProfileStore เซฟแยกกัน; ถ้าเซิร์ฟล่มระหว่างสองการเซฟอาจซ้ำ/หายได้ 1 ใบ (ยอมรับได้ในระดับนี้ ควรตรวจซ้ำตอนทดสอบหลายบัญชี).
2. ทวงไข่คืนใช้กด E ที่คนขโมย (ไม่ใช่ตีด้วยอาวุธตามคำบรรยายเดิม) — ตัดสินใจให้ทำงานได้แน่นอนบนมือถือ; ปรับเป็นการตีได้ใน Phase 10 ถ้าต้องการ.
3. โล่ AFK อาศัยเวลา idle ที่ client รายงาน (ทุก 20 วิ) — client ปลอม idle ได้ จึงล้างโล่ทันทีเมื่อเซิร์ฟเวอร์เห็นการกระทำ (ขโมย/ล็อก/ทวงคืน). ควรตรวจซ้ำก่อนเปิด Beta.
4. Mount เป็นภาพสัตว์ใต้ตัวผู้เล่น + ความเร็ว ไม่มี seat/แอนิเมชัน/กระโดดสูง/ร่อน; โมเดลสัตว์/ไข่/ผู้พิทักษ์เป็น procedural ไม่ได้ใช้ Creator Store asset รอบนี้ → Phase 10.
5. ยังไม่ทำ: กับดัก/สัตว์เฝ้าฐาน (4.7 ข้อ 8), **ตกแต่งฐาน (9.2)**, กระดาน "จอมโจรไข่" (นับ `Stats.EggsStolen` แล้ว แสดงผลใน Phase 8), ไข่ Robux/Secret/Bloodmoon (Phase 8), สัตว์/ไข่โซน 3–8 (Phase 7). ช่องพกสัตว์เพิ่ม (Rebirth/Game Pass) ผ่าน `Pets.equipSlots` ใน Phase 8.
6. ค่าทั้งหมดใน Config.Base/Pets/Eggs เป็นค่าตั้งต้นสำหรับ balance Phase 10; `balance_sim.py` ยังไม่จำลองรายได้คอก/บัฟสัตว์. มือถือ/gamepad และหลายเซิร์ฟเวอร์ยังไม่ได้ทดสอบ.
7. UI สวน (GardenController) ยังสร้างปุ่มใหม่ทุกครั้งที่ได้ GardenState (ทุก 2 วิ) จึงอาจทำให้คลิกหายแบบเดียวกับที่แก้ใน PetController — ควรแก้รูปแบบเดียวกัน.
