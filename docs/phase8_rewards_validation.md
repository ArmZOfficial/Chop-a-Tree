# Phase 8b — Daily login, Codes และ Leaderboard (core)

ทำใน Studio PlaceId `93479990217075` วันที่ 2026-10-01. Phase 8 ส่วนอื่นยังค้าง; ยังไม่ได้ Publish place.

## ระบบ

1. DailyService นับการเข้าเล่น/เปิด Daily ตามวัน UTC: วันใหม่ 00:00 UTC = 07:00 เวลาไทย. เข้าเล่นต่อกันเพิ่ม streak; ขาดวันเริ่มวันที่ 1, หลังวันที่ 7 วนรางวัลวันที่ 1. รับวันปัจจุบันได้ครั้งเดียว; ไม่รับย้อนหลัง. การเข้าเล่นโดยไม่ได้กดรับยังนับ streak. เวลาเป็นของ server; client ไม่ส่งวัน/ราคา/รางวัล.
2. Daily Rewards ใน Config.Daily: 20 Gems, 30 Gems, Rare Lv.5, 50 Gems, Wood ×2 15 นาที, 75 Gems, วันที่ 7 = 100 Gems + Epic Lv.20. หีบโซน 1 เก็บ Rot ปัจจุบันตาม Weapon.GrantChest. ค่ารางวัลเป็นค่าตั้งต้นรอจูน Phase 10.
3. Codes อยู่เฉพาะ Server.Config.Codes; trim/uppercase, จำกัด input, ตรวจเริ่ม/หมดอายุ และบันทึก stable ID ใน profile. `RELEASE` = 100 Gems + Rare Lv.5; `FORESTBOOST` = Wood ×2 15 นาที; ทั้งสองหมดอายุ 2026-11-01 00:00 UTC. ห้ามใช้ stable ID เก่ากับรางวัลใหม่. RewardService ให้ Gems/หีบ/บูสต์ในเธรดไม่มี yield เหมือน Daily; marker/เงิน/ของเซฟใน session profile เดียวกัน.
4. Boosts.Wood/Coins เป็นเวลา UTC ที่หมดอายุ, คงผ่าน reconnect/Rebirth; เวลาบูสต์ใหม่ต่อจากเวลาที่เหลือ ไม่คูณขนาดซ้ำ. Run.Award รวม friend/weather/pet/skill/timed Wood cap ×4 และ Coins friend/skill/timed cap ×4. ไม่มี EXP/Luck boost ในรอบนี้; ต่อเมื่อทำระบบที่เกี่ยวข้อง. Feature Daily/Codes ปิดรับใหม่ได้แต่รางวัลที่รับแล้วคงอยู่.
5. Leaderboard มี TreesCut, HighestHit, Rebirth, รายได้คอก/วินาที (Pet.Income); อันดับ PvP รอ Phase 9. Top 10 ในเมนูแสดง Server ค่าจริงและ Global ค่าประมาณ. กระดานเดิม 2 แผ่นในหมู่บ้านแสดง TreesCut/HighestHit พร้อม prompt เปิดเมนู. ไม่เพิ่มโมเดลแมพใหม่.
6. Global ใช้ OrderedDataStore แยกตาม Config.Leaderboards.Season/metric; Studio prefix `ChopBoards_Studio_v1_` แยกจาก `ChopBoards_v1_` เกมจริง. เขียน/อ่านรอบละ 120 วิ, อ่าน remote จาก cache เท่านั้น; pcall เครือข่าย, unavailable แสดงสถานะและใช้ Server ที่กระดาน. ออกจากเกมส่ง snapshot สุดท้าย; shutdown รอ flush ไม่เกิน 25 วิ. ชื่อคนที่อยู่เซิร์ฟใช้ DisplayName; คนออฟไลน์แสดง User ID.
7. OrderedDataStore เก็บ integer จึงใช้ log10(1+value) ×1e6 รองรับถึง 1e300; Global มีเครื่องหมาย ≈ (ตัวเลขใหญ่คลาดเคลื่อนประมาณไม่เกิน 2.4 ppm; ค่าจิ๋วมี quantization แบบ absolute). Score 1 หมายถึงค่าจริง 0; score 0 เป็น tombstone ถูกตัดจากอันดับ. ผู้เล่น Meta.AdminTouched ถูกตัดจาก Server/Global; UpdateAsync รักษา tombstone ไม่ให้ stale write คืนอันดับ. Season ใหม่แยก store แต่ Meta.AdminTouched เดิมยังถูกตัดอย่างระมัดระวัง; นโยบายกลับเข้าอันดับหลังล้างข้อมูลต้องทำแยก ไม่ลบ provenance เพื่อให้กลับเข้าเอง.
8. Schema v1 Reconcile เพิ่ม Daily/Codes/Boosts โดยไม่เปลี่ยน ProfileStore. RebirthService ไม่ลบสามชุดนี้. Remotes DailyAction/CodeAction/LeaderboardRequest ตรวจ loaded/feature และ rate limit .35/1/1 วิ; client เปลี่ยน clock/Reward หรือเรียก force ไม่ได้. RewardsHUD ปุ่มขวาบน มี Daily/Codes/อันดับ, รายการใช้ปุ่มเดิมและปรับ scale ตาม viewport. Feature Leaderboard ปิดจอ/ปุ่ม prompt ในหมู่บ้านด้วย.
9. Admin แท็บ rewards มี dailyreset (ยืนยัน), day7, codesreset (ยืนยัน), boost Wood/Coins 15 นาที และ boards status. คำสั่งเปลี่ยนรางวัล marksTarget ตามระบบเดิม; ไม่เปิดช่อง bypass ทาง remote ผู้เล่นทั่วไป.
