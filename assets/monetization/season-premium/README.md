## Description

Unlock the Premium reward track for the current season. Earn season levels through play to claim rewards. Valid for this season only.

## คำอธิบายไทย

ปลดล็อกแถวรางวัล Premium ของซีซันปัจจุบัน เล่นเพื่อเก็บเลเวลซีซันและรับรางวัล ใช้ได้เฉพาะซีซันนี้

ข้อความสั้นเป็นร่างสำหรับสิทธิ์ตามแผน ไม่รับประกันว่าจะผ่านตัวกรอง Roblox. ยังไม่ได้สร้างสินค้าใน Creator Dashboard จึงยังไม่มี Product ID; ยังไม่ได้ต่อระบบซื้อ/แถว Premium/receipt หรือ Publish. ต้องผูกสิทธิ์กับ season ID ที่ประกาศขายและป้องกันการซื้อซีซันเดียวกันซ้ำก่อนเปิดขาย. ไม่ใช่สิทธิ์ถาวรทุกซีซันและไม่ได้ปลดทุกเลเวลทันที.
