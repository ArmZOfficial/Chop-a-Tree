# Chop a Tree — กฎทำงานสำหรับ AI

## เริ่มงานและจบงาน

1. อ่าน `docs/HANDOFF.md` (สถานะ), `docs/plan.md` (ขอบเขต); เลือกอ่านเอกสารเฉพาะงานจาก `docs/INDEX.md`.
2. ทุกงานอัปเดต **plan + SKILL + handoff ในงานเดียวกัน** (ArmZ 2026-10-01): เปลี่ยนเฉพาะข้อที่เกี่ยวข้อง ไม่เติมประวัติซ้ำ. handoff เก็บสถานะล่าสุด/ผลตรวจ/งานถัดไป; รายละเอียดผลตรวจอยู่ validation.
3. Commit/push งานที่จบตามสิทธิ์เดิม. **ไม่ซื้อ Robux/asset เสียเงิน และไม่ Publish โดยไม่มีคำสั่ง**. คอสเมติกให้รอ ArmZ สั่ง.
4. อ่าน systems เฉพาะ heading ของงาน; design เป็น spec snapshot ไม่ใช่สถานะล่าสุด. จบงานตรวจลิงก์และความสอดคล้องสามไฟล์.
5. ArmZ เปิด ponytail full + caveman full (2026-10-02): ใช้ของเดิม/stdlib, diff เล็ก, รายงานไทยสั้น; เอกสาร/โค้ดเขียนปกติ. ซีซันใหม่ใช้ ID ใหม่และช่วง UTC ต่อเนื่อง (มีถึง s4 จบ 2027-02-01 UTC); ทดสอบ rollover, pending receipt ข้ามซีซัน และวันหมดซีซันสุดท้ายด้วย scenario เดิม.

## กฎที่ใช้ทุกระบบ

- Server ตรวจ owner/access/ระยะ/ราคา/รางวัล; client ส่ง intent. ใช้ Service เจ้าของระบบเดิม และ Config/Balance เดิม.
- คง schema/UID/stable ID; เติมเซฟผ่าน Reconcile. ธุรกรรมย้ายของ/จ่ายรางวัลไม่ yield; receipt ตอบ Granted หลังยืนยันเซฟ และป้องกันจ่ายซ้ำ.
- ทดสอบ service ใน Script ของ VM เกม; MCP execute_luau ตอนนี้ require ModuleScript เกมไม่ได้ (Capabilities) ใช้ RemoteFunction ตรงจาก Client หรือวาง test Script ใน Edit; **อย่า require DataService ผ่าน MCP** (cache แยก). Snapshot/restore profile, flags, weather, Balance, anchor/ตำแหน่ง; GUIHarness Finish ก่อน Stop; ลบ test scripts. Run baseline แยก Pass/boost จากบัญชีจริงและปิด autosave/leaderboard. Import เรียก Pet.Advance แบบ deferred แม้ Eggs ปิด: รอ handler แล้วคืน Pets snapshot ก่อนตรวจ restore. **อย่า overwrite ProfileStore**.
- Studio API บันทึกข้อมูลจริง. ก่อนเขียน list Studios/ตรวจ PlaceId `93479990217075`; ID Studio เปลี่ยนได้. Sync ผ่าน MCP multi_edit แล้วเทียบ source checksum; Rojo ยังไม่ได้ใช้. ReceiptPersistenceScenario ใช้ Save → reconnect → Replay; เก็บ OriginalData นอก Play และยืนยัน SaveAndWait หลังคืนข้อมูล. Synthetic receipt ไม่ใช่ paid purchase.
- GUI ตรวจคลิกจริง/ZIndex/DataPatch มาช้า; state refresh ใช้ปุ่มเดิม. Inventory ต้องรับทั้ง `Purchases.passes` และ path ลูกเพื่ออัปเดต OpenTen ขณะเปิดอยู่. ตรวจ capacity ด้วย ShopGUIHarness.SetFreeSlots: หีบ/อาวุธ/Stats ต้องเปลี่ยนเท่าจำนวนที่เปิดได้จริง. DataService.Changed deferred: รอ handler ก่อน assert.
- UI scrolling: `UIKit.ScrollEdges` owns canvas padding/scrollbar inset/clipping. **No colour fades over lists** (ArmZ rejected them twice 2026-10-03: square, then muddy over cards). Verify populated visible tabs with `tools/ui/ScrollEdgeAudit.luau` and screenshots; UIAudit skips clipped descendants. `UIKit.Tab` shrinks long labels to fit; don't set TextScaled on TabLabel. iPhone 17 Pro MCP input needs GUI center + (62.5,20.5) for the full-device/safe-area offset; assert the intended panel opened. Inventory detail dialogs use named rarity/stat tiles; Index keeps category controls outside its paged canvas. Validation: `docs/ui-polish-validation.md`.
- เปลี่ยนสูตร/ตัวเลขรัน `tools/balance_sim.py`; ทดสอบส่วนที่กระทบและบันทึกสิ่งที่ยังไม่พิสูจน์. ใช้ RegressionHarness.Prepare/Finish ครอบ scenario เก่า (baseline ไม่มี Pass/boost); คืนข้อมูลแม้ test fail. Festival query เวลาอนาคตต้องไม่ล้าง preview ปัจจุบัน. ระบบใหม่เพิ่ม AdminService.Register และ Feature Flag.
- Auto Cut ฟรี; permanent bonus ชนิดเดียวกันใช้ค่าสูงสุด/เพดานร่วมกับทางฟรี. ใช้ seam Run.Award/Pet.Mult/Balance; รายละเอียด cap อ่าน validation ของระบบ.

- Player-facing text is **bilingual EN+TH** (master prompt 2026-10-02, replaces the English-only rule): write English in code as the key; `Shared.Locale` (client `LocaleController` binds PlayerGui + Workspace) shows Thai from `Config.Strings` / catalog `.thai`. Every new string must get Thai in `assets/localization/strings.csv` (`tools/locale_extract.py --check` = 0 missing, then `tools/gen_strings.py`); dynamic text = template `{1}` keys; use `Locale.T(key, vars)` in new code when convenient. Terms: `docs/localization-glossary.md`. Keep `.thai` metadata and `.name`; never translate player names or stable IDs; mark such labels `NoTranslate` attribute. Admin UI stays English. Menu/system icons: `assets/ui/studs/icons.png` (1024, ChatGPT, Studs style), image `78845524834085`; use per-icon bounds in Config/UIIcons measured from the alpha gaps, never grid guesses. Check actual Play screenshots, contrast/cropping/overlap and clicks before claiming visual completion.
- Visual direction (ArmZ 2026-10-02): **retro classic Roblox** for world, trees and new items — Plastic + Studs top/Inlet bottom, bright BrickColors, chunky simple shapes, flat lighting; no realistic meshes/PBR for new work. Existing UI wood windows stay.
- Map rework rules: rebuild only via `ServerStorage.MapTools.MapBuilder` (fixed seed). Trees = TreeKit Kako9-style blocks (17 parts, keys like MeadowOak; `Zones.treePools` must list TreeKit keys). `BuildMountains` uses `MapAssets.StuddedRock` + invisible MountainWall; keep its boat-curve copy in sync with Config.Story. Creator Store "studded" reuploads often hide `LightConfig`/`Package` backdoors under `Weld` — strip every script before use. Every tag must survive with same attributes: Tree, PreviewTree, ChestSpot, Nest, ZoneGate, WarpStone, ZoneSpawn, BossArena, Shrine, PlayerBase, GardenSlot, Shop, NPC, ForestGate, ArenaPortal, RealmGate, Lumora, Leaderboard, ChestAltar. Trees keep `Tree` tag, Zone/Tier attributes and trunk collider PrimaryPart (TreeService). Compare `MapBuilder.Report()` before/after; run ValidateRoutes in Edit+Play. Store-pack props/VFX go through `MapBuilder.BuildDressing()` only (prototypes in `MapAssets.Nature`/`.VFX`, built by `tools/map/DressingPrototypes.luau`; no Unions — MCP threads cannot clone them); re-run it after any BuildZone/BuildVillage. Animated meshes get tag `MapFX` + `Spin`/`Bob` (client `ZoneAmbience`); pale colours on Neon wash out to white, use Glass. Zone footprint lives only in `Zones.At(pos)` (rings `inner/outer/y`, `Zones.Hub`); never re-derive it in a service. Changing Zones radii/y requires a rebuild, re-running `BuildZoneKeepers.luau`, and checking Merchant.Position. MCP threads cannot `require` game modules: use `loadstring(MapBuilder.Source)()` in Edit and a temporary ServerScriptService Script for Play checks.
- WalkSpeed: only `PetService.ApplySpeed` sets it in the main place (base × Pet.SpeedMult × sprint). New speed effects plug into that function; clients send intent only (`SprintIntent`).
- Locomotion art: `Config.Movement.LocomotionAnimation` overrides default Animate walk/run only after preload succeeds; keep avatar animations if permission/loading fails. Check real loaded tracks and respawn, not just AnimationId strings. Demo1 `103920925204515` access was granted and R15 walk/sprint verified; keep idle/jump/emotes and speed ownership intact.
- Map systems/migrations: read [docs/map-systems.md](docs/map-systems.md) before changing Zone/Gate/Travel/Explorer/events.
